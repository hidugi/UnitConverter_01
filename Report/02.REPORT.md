## 2. 8계층 + Hook — 한 줄 요약

### 2.1 누가 일하나 (Model · Agent · Harness)

| 계층 | 역할 | 비유 |
|------|------|------|
| **Model** | 판단·코드 생성 AI 두뇌 | 숙련 **엔지니어** |
| **Agent** | 파일·터미널 실행 권한을 가진 실행 AI | 출입증·공구함을 받은 **현장 반장** |
| **Harness** | 컨텍스트·모드·권한을 묶는 Cursor 실행 환경 | 도면함·규칙이 있는 **현장 사무소** |

### 2.2 무엇을 지키고 어떻게 시키나 (Rule · Skill · Command)

| 계층 | 역할 | 비유 | UnitConverter_01 현황 |
|------|------|------|----------------------|
| **Rule** | 불변 조건·금지 사항 | **헌법** (`3.28084`, yard 포함, Phase 1 OOS) | ✅ `docs/PRD.md` · ❌ `.cursor/rules/` |
| **Skill** | 작업 단계별 매뉴얼 | **작업 매뉴얼** (Red만 / Rule↔테스트 1:1) | △ 방향만 · ❌ `SKILL.md` |
| **Command** | 한 번에 실행할 명령 | **버튼** (`/tdd-red`, `convert_length`) | ✅ PRD 설계 · ❌ 구현·슬래시 명령 |

### 2.3 무엇으로 검증하나 (Tool/MCP · Test/Review Loop)

| 계층 | 역할 | 비유 | UnitConverter_01 현황 |
|------|------|------|----------------------|
| **Tool / MCP** | Agent 손·외부 연동 | **공구·외주 연락망** | Cursor 기본 Tool |
| **Test / Review Loop** | Red→Green→Refactor·검토 | **CCTV + 품질검사 라인** | PRD §8 정의 · Harness 준비됨 |

### 2.4 Hook

| 계층 | 역할 | 비유 | UnitConverter_01 현황 |
|------|------|------|----------------------|
| **Hook** | 이벤트 전후 자동 검사·실행 | **자동문·CCTV 알람** | ❌ `hooks.json` |

## 4. ECB Harness — 생성 결과

### 4.1 디렉터리 구조

```
UnitConverter_01/
├── pyproject.toml
├── src/
│   ├── entity/__init__.py      # (빈 패키지)
│   ├── control/__init__.py
│   └── boundary/__init__.py
└── tests/
    ├── entity/__init__.py
    ├── control/__init__.py
    └── boundary/__init__.py
```

### 4.2 `pyproject.toml` 요약

| 항목 | 값 |
|------|-----|
| 프로젝트명 | `unit-converter` 0.1.0 |
| dev 의존성 | `pytest>=8.0` 만 |
| `testpaths` | `tests` |
| `pythonpath` | `src` |

### 4.3 ECB ↔ 레이어 매핑 (이후 구현)

| ECB | `src/` | `tests/` | 담당 |
|-----|--------|----------|------|
| **Entity** | `src/entity/` | `tests/entity/` | 비율·도메인 규칙 (INV) |
| **Control** | `src/control/` | `tests/control/` | `convert_length` 흐름·검증 순서 |
| **Boundary** | `src/boundary/` | `tests/boundary/` | CLI·출력 포맷 (후속) |

**범위:** 코드·테스트 **본문은 미작성**. Harness 골격만 확정.

### 4.4 pytest 상태

- Harness 생성 후 `pytest tests/ -v` → **0 tests collected** (정상)
- venv에 pytest 미설치 시 로컬에서 `pip install pytest` 필요 (SSL 환경 이슈 가능)
