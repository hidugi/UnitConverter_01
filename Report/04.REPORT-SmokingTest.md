### 5.2 GUI smoke (프로그래밍 방식)

`QApplication` + `UnitConverterWindow` 생성 → Unit=`meter`, Value=`2.5` → Convert:

```powershell
python -c "
import sys
from pathlib import Path
sys.path.insert(0, str(Path('src').resolve()))
from PyQt6.QtWidgets import QApplication
from boundary.gui import UnitConverterWindow

app = QApplication(sys.argv)
w = UnitConverterWindow()
w._unit_combo.setCurrentText('meter')
w._value_spin.setValue(2.5)
w._on_convert()
print(w._result_view.toPlainText())
"
```

**결과:** `SMOKE OK`

```
2.5 meter = 2.5 meter
2.5 meter = 8.2 feet
2.5 meter = 2.7 yard
```
