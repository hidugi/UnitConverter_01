### 3.4 핵심 구현 결정

#### (1) D-005 `yard:2.7` 픽스처 — meter 허브 반올림

`yard:2.7` 입력 시 meter를 1자리 반올림(`2.5`)한 뒤, **입력 단위는 원값 유지**, 나머지는 반올림된 meter 허브에서 환산:

```python
meter_display = round(meter_value, 1)
meter_out = value if unit == "meter" else meter_display
feet_out = value if unit == "feet" else round(meter_display * FEET_PER_METER, 1)
yard_out = value if unit == "yard" else round(meter_display * YARD_PER_METER, 1)
```

→ PRD §5.3 픽스처 3건(`meter:2.5` / `feet:8.2` / `yard:2.7` 동치) 일치

#### (2) D-006 assert 보정

RED 스켈레톤 `round(2.5 * 3.28, 1) != 8.2`는 수학적으로 성립하지 않음(둘 다 8.2).  
GREEN 시 비반올림 값 비교로 SC-2 의도에 맞게 수정:

```python
wrong_feet = 2.5 * 3.28
exact_feet = 2.5 * FEET_PER_METER
assert wrong_feet != exact_feet
assert round(exact_feet, 1) == 8.2
```

#### (3) U-001~U-003 Mock + U-004 control 연동

- U-001~U-003: `patch("boundary.cli.convert_length", ...)` — I/O Mock 허용 (UI Track)
- U-004: `from control.convert_length import convert_length` — 실제 e2e smoke
